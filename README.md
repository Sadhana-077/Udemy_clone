# 🎓 Udemy Clone

A responsive **Udemy landing page clone** built using **HTML5** and **CSS3**. This project recreates the look and feel of the Udemy homepage with a modern layout, course cards, categories, topics, and footer.

## 🚀 Features

- Responsive navigation bar
- Search bar with Font Awesome icons
- Course categories section
- Promotional banner
- Recommended courses section
- Topics recommendation section
- Most Popular courses section
- Responsive Flexbox layout
- Footer with useful links

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts (Gabarito)
- Font Awesome

## 💻 How to Run

1. Clone the repository

```bash
git clone https://github.com/Sadhana-077/Udemy-Clone.git
```

2. Open the project folder.

3. Double-click **index.html** or open it using **Live Server** in VS Code.
